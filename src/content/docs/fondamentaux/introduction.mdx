## Qu'est-ce qu'un service web ?

Un service web permet à des applications de dialoguer à distance sur le réseau. On parle d'**API** (*Application Programming Interface*, en français « interface de programmation applicative ») : une application **expose des services** consommables par d'autres logiciels.

Historiquement, deux grandes approches coexistent pour concevoir des API (c'est l'architecture **REST**, théorisée par Roy Fielding en 2000, qui est aujourd'hui la norme sur le web) :

| Critère | SOAP (*Simple Object Access Protocol*) | REST (*REpresentational State Transfer*) |
| --- | --- | --- |
| **Protocole** | Générique (peut passer par HTTP ou d'autres protocoles, mais n'exploite pas les spécificités de HTTP) | S'appuie directement sur le protocole **HTTP** |
| **Format** | **XML** uniquement (structure imposée) | Libre (**JSON** majoritaire, XML, texte, binaire…) |
| **Approche** | Appels d'opérations sur une adresse unique (ex. `getUser`, `createUser`) | Manipulation de **ressources** identifiées par des **URI** (ex. `/users/1`) |

Exemple public pour tester : [JSONPlaceholder](https://jsonplaceholder.typicode.com/)
- Obtenir la liste des utilisateurs : [https://jsonplaceholder.typicode.com/users](https://jsonplaceholder.typicode.com/users)

## Les formats de données XML et JSON

- Les formats **JSON** et **XML** permettent de stocker et d'échanger des données textuelles de manière structurée.
- Le **JSON** est plus léger et constitue aujourd'hui le standard largement majoritaire pour les API REST.

### Objet Java source

```java title="Personne.java"
@XmlRootElement
public class Personne {
  private String prenom;
  private Integer age;
  private Adresse adresse;
}

@XmlRootElement
public class Adresse {
  private String nomCommune;
  private String codePostal;
}
```
