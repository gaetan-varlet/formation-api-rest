## Configuration de la source de données (H2 vs PostgreSQL)

Dans `src/main/resources/application.properties`, commencez par configurer la connexion propre au moteur de base de données :

<Tabs>
<TabItem label="H2 (en mémoire / local)">

Avec la dépendance `h2` dans le `pom.xml`, aucune installation de serveur SQL n'est requise :

```properties title="src/main/resources/application.properties"
spring.datasource.driver-class-name=org.h2.Driver
# Fixe le nom de la BDD pour ne pas générer une URL aléatoire à chaque démarrage
spring.datasource.url=jdbc:h2:mem:testdb
spring.datasource.username=sa
spring.datasource.password=
# Active la console web H2 accessible dans le navigateur
spring.h2.console.enabled=true
```

Console web H2 disponible après démarrage : [http://localhost:8080/h2-console](http://localhost:8080/h2-console)

</TabItem>
<TabItem label="PostgreSQL (hors-prod / prod)">

Dans le `pom.xml`, remplacez (ou complétez) la dépendance `h2` par le driver PostgreSQL :

```xml title="pom.xml"
<dependency>
    <groupId>org.postgresql</groupId>
    <artifactId>postgresql</artifactId>
    <scope>runtime</scope>
</dependency>
```

Puis adaptez les propriétés de connexion dans `application.properties` :

```properties title="src/main/resources/application.properties"
spring.datasource.driver-class-name=org.postgresql.Driver
spring.datasource.url=jdbc:postgresql://dvtoucanldb01.ad.insee.intra:1983/di_pg_toucan_dv01
spring.datasource.username=***
spring.datasource.password=***
```

</TabItem>
</Tabs>

### Configuration JPA / Hibernate commune (H2 et PostgreSQL)

Ajoutez ensuite la configuration JPA commune, quel que soit le moteur utilisé :

```properties title="src/main/resources/application.properties"
# Désactive la création automatique des tables par Hibernate (on utilise schema.sql)
spring.jpa.hibernate.ddl-auto=none
```

## Initialisation des tables et des données

Créez `schema.sql` et `data.sql` dans `src/main/resources/`. Avec une base embarquée (H2) et `ddl-auto=none`, Spring Boot les exécute automatiquement au démarrage (d'abord `schema.sql`, puis `data.sql`) :

<Tabs>
<TabItem label="schema.sql">

```sql title="src/main/resources/schema.sql"
CREATE TABLE VIN (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    chateau VARCHAR(100) NOT NULL,
    appellation VARCHAR(100),
    prix DECIMAL(10,2)
);
```

</TabItem>
<TabItem label="data.sql">

## Création de l'entité Java (JPA)

Créez la classe métier mappée sur la table `vin` :

```java title="src/main/java/fr/insee/formationapirest/model/Vin.java"
package fr.insee.formationapirest.model;

import jakarta.persistence.Entity;
import jakarta.persistence.GeneratedValue;
import jakarta.persistence.GenerationType;
import jakarta.persistence.Id;
import jakarta.persistence.Table;

@Entity
@Table(name = "vin")
public class Vin {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    private String chateau;
    private String appellation;
    private Double prix;
}
```

:::caution[N'oubliez pas les getters et setters]
Sans getters/setters, Jackson ne pourra pas sérialiser les champs en JSON lors de vos appels API. Si vous utilisez **Lombok**, placez les annotations **`@Getter`** et **`@Setter` sur la classe** (et non sur les attributs) :

```java
@Getter
@Setter
@Entity
@Table(name = "vin")
public class Vin { ... }
```
:::

:::note[Rappels JPA : configuration, annotations et clés primaires]
Pour approfondir les valeurs de `ddl-auto`, l'utilisation d'un schéma autre que `public`, le rôle des annotations (`@Entity`, `@Table`, `@Id`, `@GeneratedValue`, `@Column`) et le choix de la clé primaire (`Long` en `IDENTITY` vs `SEQUENCE` vs `UUIDv7`), consultez la page [Rappels JPA : entités, mapping et clés](/formation-api-rest/acces-donnees/rappels-jpa/).
:::

## Création du Repository (DAO)

- `JpaRepository<T, ID>` est une interface Spring Data JPA (appuyée sur Hibernate) qui fournit nativement toutes les opérations CRUD (`findAll`, `findById`, `save`, `deleteById`…).
- En **étendant** cette interface, on précise le type de l'entité (`Vin`) et le type de sa clé primaire (`Long`) :

```java title="src/main/java/fr/insee/formationapirest/repository/VinRepository.java"
package fr.insee.formationapirest.repository;

import org.springframework.data.jpa.repository.JpaRepository;
import fr.insee.formationapirest.model.Vin;

public interface VinRepository extends JpaRepository<Vin, Long> {
}
```

*(Note : `@Repository` est facultatif sur une interface qui étend `JpaRepository`, Spring la détecte automatiquement.)*

## Tester le bon fonctionnement avec un premier endpoint

Pour vérifier dès maintenant que les scripts SQL, l'entité `Vin` et `VinRepository` fonctionnent ensemble, créez un contrôleur minimal exposant `GET /vins` :

```java title="src/main/java/fr/insee/formationapirest/controller/VinController.java"
package fr.insee.formationapirest.controller;

import java.util.List;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;
import fr.insee.formationapirest.model.Vin;
import fr.insee.formationapirest.repository.VinRepository;
import lombok.RequiredArgsConstructor;

@RestController
@RequestMapping("/vins")
@RequiredArgsConstructor
public class VinController {

    private final VinRepository vinRepository;

    @GetMapping
    public List<Vin> getAll() {
        return vinRepository.findAll();
    }
}
```

Démarrez l'application et accédez à [http://localhost:8080/vins](http://localhost:8080/vins) : vous devez obtenir la liste des 4 vins de `data.sql` au format JSON. *(Nous complèterons ce contrôleur avec le reste du CRUD dans [Création d'une API CRUD](/formation-api-rest/api-rest/creation-crud/).)*

:::note[En projet (hors formation) : exclure H2 du JAR]
Si H2 reste présent dans le `pom.xml` pour le développement local, pensez à l'exclure lors du packaging du `.jar` de production :

```xml title="pom.xml"
<plugin>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-maven-plugin</artifactId>
    <configuration>
        <excludes>
            <exclude>
                <groupId>com.h2database</groupId>
                <artifactId>h2</artifactId>
            </exclude>
        </excludes>
    </configuration>
</plugin>
```
:::
