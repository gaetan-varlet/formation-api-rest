## Configuration de la source de données (H2 vs PostgreSQL)

Dans `src/main/resources/application.properties`, vous configurez la connexion à la base de données selon l'environnement :

<Tabs>
<TabItem label="H2 (en mémoire / local)">

Avec la dépendance `h2` dans le `pom.xml`, aucune installation de serveur SQL n'est requise :

```properties title="src/main/resources/application.properties"
# Active la console H2 accessible dans le navigateur
spring.h2.console.enabled=true
# Fixe le nom de la BDD pour ne pas générer une URL aléatoire à chaque démarrage
spring.datasource.url=jdbc:h2:mem:testdb
spring.datasource.username=sa
spring.datasource.password=
# Désactive la création automatique des tables par Hibernate (on utilise schema.sql)
spring.jpa.hibernate.ddl-auto=none
# Précise le schéma par défaut sur lequel les entités Java sont mappées
spring.jpa.properties.hibernate.default_schema=formation
```

Console web H2 disponible après démarrage : [http://localhost:8080/h2-console](http://localhost:8080/h2-console)

</TabItem>
<TabItem label="PostgreSQL (hors-prod / prod)">

Dans le `pom.xml`, remplacez (ou complétez) la dépendance `h2` par le driver PostgreSQL :

```xml title="pom.xml"
<dependency>
    <groupId>org.postgresql</groupId>
    <artifactId>postgresql</artifactId>
    <scope>runtime</scope>
</dependency>
```

Puis adaptez `application.properties` :

```properties title="src/main/resources/application.properties"
spring.datasource.driver-class-name=org.postgresql.Driver
spring.datasource.url=jdbc:postgresql://dvtoucanldb01.ad.insee.intra:1983/di_pg_toucan_dv01
spring.datasource.username=***
spring.datasource.password=***
```

</TabItem>
</Tabs>

## Initialisation des tables et des données

Créez `schema.sql` et `data.sql` dans `src/main/resources/`. Avec une base embarquée (H2) et `ddl-auto=none`, Spring Boot les exécute automatiquement au démarrage (d'abord `schema.sql`, puis `data.sql`) :

<Tabs>
<TabItem label="schema.sql">

```sql title="src/main/resources/schema.sql"
CREATE SCHEMA formation;

CREATE TABLE formation.VIN (
    id INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    chateau VARCHAR(100) NOT NULL,
    appellation VARCHAR(100),
    prix DECIMAL(10,2)
);
```

</TabItem>
<TabItem label="data.sql">

```sql title="src/main/resources/data.sql"
INSERT INTO formation.vin (chateau, appellation, prix) VALUES ('Château Margaux', 'Margaux', 500);
```

## Création de l'entité Java (JPA)

Créez la classe métier mappée sur la table `vin` :

```java title="src/main/java/fr/insee/formationapirest/model/Vin.java"
package fr.insee.formationapirest.model;

import jakarta.persistence.Entity;
import jakarta.persistence.GeneratedValue;
import jakarta.persistence.GenerationType;
import jakarta.persistence.Id;
import jakarta.persistence.Table;

@Entity
@Table(name = "vin") // possibilité de surcharger le schéma : @Table(name = "vin", schema = "nomSchema")
public class Vin {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Integer id;

    private String chateau;
    private String appellation;
    private Double prix;

    // Ajouter les getters et setters (ou utiliser @Getter @Setter de Lombok)
}
```

## Création du Repository (DAO)

- `JpaRepository<T, ID>` est une interface Spring Data JPA (appuyée sur Hibernate) qui fournit nativement toutes les opérations CRUD (`findAll`, `findById`, `save`, `deleteById`…).
- En **étendant** cette interface, on précise le type de l'entité (`Vin`) et le type de sa clé primaire (`Integer`) :

```java title="src/main/java/fr/insee/formationapirest/repository/VinRepository.java"
package fr.insee.formationapirest.repository;

import org.springframework.data.jpa.repository.JpaRepository;
import fr.insee.formationapirest.model.Vin;

public interface VinRepository extends JpaRepository<Vin, Integer> {
}
```

*(Note : `@Repository` est facultatif sur une interface qui étend `JpaRepository`, Spring la détecte automatiquement.)*

## Préparer le livrable : exclure H2 du JAR

Si H2 reste présent dans le `pom.xml` pour le développement local, pensez à l'exclure lors du packaging du `.jar` de production :

```xml title="pom.xml"
<plugin>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-maven-plugin</artifactId>
    <configuration>
        <excludes>
            <exclude>
                <groupId>com.h2database</groupId>
                <artifactId>h2</artifactId>
            </exclude>
        </excludes>
    </configuration>
</plugin>
```
